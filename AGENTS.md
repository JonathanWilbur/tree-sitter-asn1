# AGENTS.md

## ASN.1 Documentation

The entire ASN.1 syntax is represented as BNF in `doc/asn1.bnf`.

The section of ITU-T Recommendation X.680 defining lexical elements, such as
`typereference` is in `doc/lexical-items.md`.

There are many well-formed ASN.1 modules in `test/asn1`.

## Tree Sitter Usage

This is just a standard tree-sitter grammar that was created with
`tree-sitter init`, so usage is standard too.
